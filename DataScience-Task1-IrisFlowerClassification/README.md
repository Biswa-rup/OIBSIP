# Iris Flower Classification

## OASIS Infobyte Data Science Internship

This project was completed as part of the OASIS Infobyte Data Science Internship.

## Project Objective

The objective of this project is to develop machine learning classification models to predict the species of Iris flowers based on their sepal and petal measurements.

## Dataset

The Iris dataset is obtained from Scikit-learn and contains 150 samples belonging to three species:

- Iris Setosa
- Iris Versicolor
- Iris Virginica

The features used are:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Methodology

The project includes:

1. Data loading
2. Exploratory Data Analysis (EDA)
3. Missing-value analysis
4. Descriptive statistics
5. Feature distribution visualization
6. Correlation analysis
7. Feature importance analysis
8. 80/20 train-test split
9. Feature scaling
10. Machine learning model training
11. 5-fold cross-validation
12. Model evaluation
13. Confusion matrix analysis
14. Model comparison
15. Best-model selection

## Machine Learning Models

The following classification algorithms were implemented:

- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree
- Random Forest

## Evaluation Metrics

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- 5-Fold Cross-Validation
